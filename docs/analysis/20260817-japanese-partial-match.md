# 日本語の部分一致が上位を取る歪みと、被覆率で塞いだ記録

<a id="ff9299d5-3dfb-4ad0-9b3b-f5d597271cdc"></a>

日付: 2026-08-17。対象: 実データのストア(/work2/llm_playground_host_dir/uniqnode-store。
仕様書 PDF 25 本 + 論文 1 本 + 書誌メモ 1 本、25,754 オブジェクト)。きっかけ: 利用者が
ビューワで「割り込み無効化」と引いたところ、無関係な論文の書誌メモが 1 位に出た。

## 何が起きていたか

BM25 は日本語を文字 bigram で索引する(SEARCH
(uuid:19574e78-9bf5-4f87-a4c2-c4a10222c580))。「割り込み無効化」は
`割り` `り込` `込み` `み無` `無効` `効化` の 6 語に切れる。このうち `り込` と `込み` が、
書誌メモの「取り込み済み」に一致していた。

| 問い | BM25 の結果(被覆前) |
|---|---|
| 割り込み無効化 | arxiv_2602_06052_meta のみ(得点 22.5) |
| 割り込み | 同上(22.5) |
| 取り込み | 同上(33.7) |
| 無効化 / 無効 | 0 件 |
| 込み(単独) | 同上(11.2) |

英語コーパスの中では日本語 bigram の df が 1 なので idf が跳ね上がり、6 語中 2 語しか
当たっていない文書が 22.5 という高得点を取る。RRF は順位しか見ないため、この 1 件は
「BM25 の 1 位」として意味検索の 1 位と同じ重み(1/61)を持ち、同点になって先頭を争って
いた。

副作用として、「BM25 が 1 語も一致せず融合が効いていない」という既存の警告が消える。
偽の一致があるために、片肺であることを言う条件を満たさなくなるためである。実際、
無関係な「メモリ管理」ではその警告が出るのに、「割り込み無効化」では出ていなかった。

この歪みは日本語の文書を 1 本入れた時点で生じる。今回は書誌メモがきっかけだが、
uniqnode 自身の docs/ のような日本語文書を取り込めば同じことが起きる。

## 被覆率の実測(閾値をどこに置くか)

順位付けの前に、実データへの問い 11 本で「クエリの異なり語のうち何語に当たったか」を
測った。値ははっきり二つに割れる。

| 問い | 被覆 |
|---|---|
| disable interrupts | 2/2 = 1.00 |
| SYSCALL instruction description operation | 4/4 = 1.00 |
| RTL8139 Transmit Status Descriptor TSD OWN bit TOK | 8/8 = 1.00 |
| xHCI transfer ring cycle bit producer consumer | 7/7 = 1.00 |
| CLI instruction clears the interrupt flag to disable maskable interrupts | 10/10 = 1.00 |
| red zone 128 bytes beyond the stack pointer leaf function signal handler | 11/12 = 0.92 |
| which field reports the period at which the HPET main counter increments | 9/10 = 0.90 |
| 割り込み無効化 | 2/6 = 0.33 |
| 文書の取得 | 1/4 = 0.25 |
| メモリ管理 | 0/4 = 0.00 |
| 世代の整合 | 0/4 = 0.00 |

英語の問いは 2 語でも 12 語でも 0.90 以上に収まる。コーパスが英語なので、当たるチャンクは
問いの語をほぼ全部持っているからである。日本語の部分一致は 0.25〜0.33 で、谷は 0.33 と
0.90 のあいだにある。定数 MIN_FUSION_COVERAGE はその中の 0.5 に置いた。

## 入れた対処

- BM25 の得点に被覆率を掛ける(古典的な coord)。当たった語が稀だというだけで、問いの
  一部にしか当たっていないチャンクを上位に置かない。
- 被覆が MIN_FUSION_COVERAGE を下回る順位は、融合の入力から外す。得点を下げるだけでは
  足りない: RRF は順位しか見ないので、1 件しか無い弱い順位でもその 1 件は「1 位」になる。
- 外したときは理由を応答の degraded で言う(「BM25 は問いの 6 語のうち最大 2 語(被覆
  0.33)にしか当たらないので、融合に入れていない」)。黙って劣化しない(should/0128)。
- 方式に bm25 を明示した要求には掛けない。語の一致そのものを求めている呼び手には、
  当たった通りを(被覆率を掛けた得点で)返す。

## 効き目

固定コーパスの評価ハーネス(EVAL (uuid:1109a04b-923e-4493-8f00-d704047d6a2a))では、
融合の数値が上がった。この合成コーパスは日本語と英語の文書を混ぜて持つので、同じ歪みを
小さく再現していたことになる。

| 方式 | 指標 | 被覆前 | 被覆後 |
|---|---|---|---|
| hybrid | Recall@1 | 0.684 | 0.895 |
| hybrid | Recall@5 | 0.947 | 1.000 |
| hybrid | MRR | 0.791 | 0.932 |
| embedding | (変化なし) | 0.896 | 0.896 |

被覆前は「この固定コーパスでは埋め込み単独の MRR が融合を上回る」ことが記録された事実
だったが、被覆後は逆転して融合が上回る(0.932 対 0.896)。融合を押し下げていたのが部分
一致の混入だったということである。

実データでは、報告された問いの 1 位から書誌メモが消え、英語の問い 6 本と日英併記の問い
1 本は 1 位が変わらなかった(sdm_vol2 p.266 CLI、sdm_vol2 p.1414 SYSCALL、hpet_1_0a p.11、
sysv_abi_0_99 p.17、rtl8139pg p.2、arxiv_2602_06052 p.3、sdm_vol3 p.197)。

## 残る限界

- 純日本語の問いが英語コーパスに当たらないこと自体は直っていない。「割り込み無効化」の
  上位は依然として的外れで、正解(sdm_vol2 p.266 の CLI、sdm_vol3 p.196 の ENABLING AND
  DISABLING INTERRUPTS)には英語か日英併記でしか届かない。被覆率が直したのは「無関係な
  文書が語の一致を装って 1 位を取る」ことだけである。今は degraded がそう言う。
- 既定の方式の境目(EMBEDDING_ONLY_TOP_K = 3)は、被覆を効かせる前の順位で測った数値
  (20260817-real-corpus-search-quality (uuid:faeda9ac-5e9e-4091-8122-2fba9f80c8db))に
  基づいている。融合の側が改善したので、境目は測り直す価値がある。未実施。
- 被覆の分母はクエリの異なり語である。同じ語を繰り返す問いや、極端に長い問いでの挙動は
  測っていない。
