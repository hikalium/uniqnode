## 明示的な残件

- 機会層の evict の物理回収: pack の書き直し(GC)。現状は容量会計と admission
  (容量超過の put 拒否)のみで、ディスクは追記のまま減らない。
- min_replicas=0(機会層のみ)の LRU+参照カウント evict(SPEC §5.4)。上の GC が前提。
- kind: search クエリと検索(RAG)層の索引。QUERY メッセージ署名(要求者の認証)もここから。
  要求者認証が入るまで、応答側の trust_level 別フィルタは実装できない(現状の応答側は
  ローカル API として全要求に応じる)。
- 失効文とグループ設定の伝播交換への載せ替え(現状は groups.json への手動配置)。
- 二重オープン検査のテストが全体並列実行で一度だけ失敗した(単独・再実行では8回再現せず)。
  再発したら expect の表示するエラー内容から追う。
